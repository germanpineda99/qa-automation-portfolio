# Public API testing examples

`postman-collection.json` is an independently authored Postman collection for
the public JSONPlaceholder practice API. It contains executable-looking GET,
POST, PUT, DELETE, and negative-response examples with local assertions for
status codes, response structure, and response content.

## Use

1. Import the collection into Postman.
2. Review the request URLs and test scripts.
3. Run requests only when you choose to access the public practice service.

No API request has been executed or reported as passing by this repository.
The collection contains examples and assertions, not execution evidence. It
contains no tokens, credentials, internal endpoints, or employer material.
