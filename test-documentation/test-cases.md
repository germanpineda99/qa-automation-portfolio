# Test cases: public demo login

These are authored cases for the public practice application. They describe
expected behavior; they are not execution evidence by themselves.

| ID | Scenario | Expected result |
|---|---|---|
| TC-001 | Valid demo credentials | User reaches secure area |
| TC-002 | Invalid password | Error displayed |
| TC-003 | Empty username | Username error displayed |
| TC-004 | Empty password | Password error displayed |
| TC-005 | Logout after login | User returns to login page |

These cases were written independently for the public demo at https://the-internet.herokuapp.com/login.
